Spirit Grove: The Possession Surge (hosted build) — an exported Slot Skeleton Studio game.

To play:
  1. Unzip this folder.
  2. Open index.html in a browser.

It is fully self-contained: no studio, no server and no internet are needed. If a browser blocks it
when opened directly from the file (some do, for local files), serve the folder over any static web
server instead — e.g. run "npx serve" in this folder, or host it — and open the address it prints.

Controls: tap / click SPIN (or press Space); T toggles turbo.

This is a SCRAMBLED build: the game code is minified and the game data is packed into an opaque
blob (data.js), so the layout, rules and asset list are not plainly readable.
